# Profile Chainage Marker

Плагин QGIS (3.28+) для разметки линий-профилей точками с подписью по длине.

## Скачать

Прямая ссылка на ZIP:  
https://github.com/kurbedoho/profile_chainage_marker/releases/latest/download/profile_chainage_marker.zip

Страница релизов: https://github.com/kurbedoho/profile_chainage_marker/releases

## Установка на любом компьютере

### Способ 1 — из ZIP (самый простой)

1. Скачайте `profile_chainage_marker.zip` по ссылке выше.
2. В QGIS: **Модули → Управление и установка модулей → Установить из ZIP**.
3. Выберите скачанный zip → **Установить**.
4. Включите модуль **Profile Chainage Marker**.
5. Меню **Vector → Profile Chainage Marker** (на русском QGIS — **Разметка профилей**).

Язык интерфейса: по умолчанию как у QGIS (**Авто**). Можно выбрать English / Русский в окне плагина — выбор запоминается.

### Способ 2 — вручную

Скопируйте папку `profile_chainage_marker` в:

`%AppData%\QGIS\QGIS3\profiles\default\python\plugins\`

Перезапустите QGIS и включите модуль.

## Как пользоваться

1. Добавьте линейный слой в проект и выберите его в окне плагина.
2. Задайте шаг и старт подписи (по умолчанию 0); при необходимости примените ко всем строкам.
3. **Длина разметки** по умолчанию = реальная длина, округлённая до целых (можно править в таблице).
4. Галочка **Развернуть** — только для расчёта, исходный слой не меняется.
5. Опционально: **Ставить точки на изгибах** (отметки масштабируются под финальную длину разметки).
6. **Создать точки** → временный слой `profile_marks` (`profile_id`, `mark`, `seq`).

Единицы — единицы CRS слоя. На карте: зелёный старт, красный конец, стрелки вдоль геометрии.
